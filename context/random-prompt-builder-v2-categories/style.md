# Style Category

## Purpose

The style category is reserved for generated visual style, medium, rendering, or aesthetic prompt fragments.

Before adding or changing any Style value, builder, generator, state, tag, condition, or validation, check `context/random-prompt-builder-v2-category-relations.md`. Update that central relation map immediately if the change creates or changes any relation with Clothing Style, Composition, Lighting, Quality, Subject, or Environment.
